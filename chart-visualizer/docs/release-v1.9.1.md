# 风沙图表工作台 v1.9.1

![v1.9.1 升级全景图](assets/fengsha-v1.9.1-upgrade-overview.png)

## 本次修复

- 修复 Mermaid AI 生成结构化 `fengsha.plan/v1` 时，过程预览长期停在 `schemaVersion` 的问题。
- Mermaid 画布与可视化画布统一使用同一套流式预览内核，结构化计划、Mermaid 和 draw.io 内容都会随分片持续更新。
- 支持 CPA/OpenAI 兼容代理常见的文本数组分片、`response.output_text.delta`、多行 SSE，以及错误标记为 `text/plain` 的流式响应。
- 普通 JSON 即使被网关误标为 `text/plain`，仍能安全识别，避免兼容修复引入回归。
- 流式文本改用独立定时刷新，窗口切换、最小化或动画帧暂停时仍会持续同步。
- 活动超时只在收到新的有效文本后续期，代理只发心跳时不会无限显示“正在生成”。

## 验收标准

1. 结构化流程图生成未完成时，第一帧能看到标题与 `schemaVersion`。
2. 后续分片到达后，同一预览会继续显示新节点和业务文字，不停留在第一帧。
3. 任务完成后继续执行本地编译、自动修复和专业质量检查，现有候选应用逻辑不变。
4. 关闭 AI 面板、切换到其他页面再返回，任务和已接收内容仍可恢复。
