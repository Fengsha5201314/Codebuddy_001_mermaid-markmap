# 可靠制图交付 v1.9 实施规格

## 目标

把 Mermaid、draw.io 可视化画布、桌面导出和 `fengsha-diagram` CLI 收敛到同一条“生成 → 校验 → 局部修复 → 安全交付 → 质量回执”链路，同时保留现有双画布编辑体验和用户数据。

## 必须实现

1. 提供一个共享的可靠交付深模块，输出稳定诊断码、具体对象、测量证据、受支持修复方式和质量检查回执。
2. Mermaid 与 draw.io 都检查结构、引用、非有限几何、空内容、文字可见性、节点重叠、画布裁切和导出尺寸；无法确定的人工审美结论必须标记为 `pending`。
3. AI 候选只有通过共享检查才可应用；失败时保留当前正常图，并把机器诊断交给修复循环。
4. 文档切换或应用重启后保留最后有效图、候选、流式输出和中断说明；不能把已中断任务显示为仍在运行。
5. CLI 新增 `deliver`、`visual-check`、`compile --target mermaid|drawio` 和可安装 Agent Skill；JSON 输出包含诊断、检查项、输入/输出哈希、字节数、尺寸、版本和人工视觉状态。
6. CLI 覆盖已有文件时必须可恢复：任何渲染、检查、写入或提交失败都不得破坏旧文件。
7. 桌面 Mermaid 导出和可视化画布导出显示同一套“标准/专业”质量结果，并且 PNG/SVG 使用与预览一致的规范图形。
8. 更新图文文档、版本号、安装包和桌面快捷方式；保留用户数据和 AI 配置。

## 非目标

- 不增加第三套渲染器，不替换 Mermaid 或 draw.io。
- 不承诺自动检查能够证明业务事实正确或人工审美已经通过。
- 本轮不实现多人协作、账号、积分、支付、托管分享、动画或复杂交互 HTML。

## 验收

- 当前 199 项测试保持通过，并新增统一诊断、原子交付、CLI 回执、Agent Skill、任务恢复和双画布质量测试。
- 同一坏图重复检查返回相同诊断码与对象。
- 中文长文本、非法引用、重叠节点、裁切图形、坏 XML、超大导出和并发覆盖均有确定性结果。
- `deliver` 失败时旧文件哈希不变；成功时文件哈希与回执一致。
- 安装后的 CLI 在桌面应用未打开时独立运行，桌面快捷方式显示并启动新版本。
