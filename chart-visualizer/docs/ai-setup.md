# AI 模型接入说明

当前支持 **CPA AI**、**DeepSeek** 和一个 **OpenAI 兼容的自定义 API**。密钥由本地服务端保存，不会写入浏览器、本地图表数据或导出文件。

> 使用 AI 时，当前图表内容和本次指令会发送给所选模型服务。请先确认该服务可以处理你的数据，不要发送密码、密钥或未经授权的敏感资料。

## 首次配置

1. 打开右上角“设置”。
2. 进入“AI 模型”。
3. 在 CPA、DeepSeek 或自定义 API 中填写接口地址与 API Key，然后点击“保存连接”。
4. 点击“获取模型”，从下拉框选择模型，再点击“启用模型”。
   - CPA / 自定义模型如果确实支持视觉输入，可为已启用模型打开“图片识别”。
   - DeepSeek 当前按文字模型处理，不提供图片开关。
5. 回到 AI 助手，从底部输入区的模型下拉框选择已启用模型。

可以同时启用多个模型。AI 输入区的模型下拉框只会显示已启用的模型，并允许随时切换。

## 专业任务模板与统一识别

AI 助手不要求用户先选择“新建、修改、修复或解释”。打开助手后，可以直接描述需求；空白对话会展示“优化结构”“补全流程”“排查问题”“转换图种”“解释与评审”“从描述创建”等专业任务模板，已有对话可从底部“快捷任务”再次调用模板。

提交时，软件会先识别当前项目和页面是否存在 Mermaid 源码或可视化画布：有内容时会把当前图、该项目当前对话和需求一并发送，由 AI 判断应当修改、修复、转换还是仅做解释；没有内容时才会从描述创建新图。

输入内容并点击“发送”即可与 AI 连续讨论，让它先归纳目标和关键歧义；确认方向后，通过独立操作栏点击“生成候选”。对话按项目保存，每段最多保留最近 120 条消息，可新建多段对话或切换历史记录，Mermaid 与可视化画布共享同一项目上下文。长对话发送给模型时会保留最初目标，并按长度选取最近上下文。提交后内容会边生成边显示，需要中止时可以点击“停止”。

可以主动附加 PNG、JPG、WebP、GIF，以及文本、Markdown、CSV、JSON、XML、Mermaid 和常见代码文件。截图可以直接在任一 AI 输入框中按 `Ctrl+V` 粘贴，粘贴成功后会显示缩略图；普通文字粘贴不受影响。音频、视频和不支持的二进制文档不会接收。DeepSeek 遇到图片会在发送前明确提示；CPA / 自定义模型只有开启“图片识别”后才能发送图片。

完整结果返回后，软件会先检查 Mermaid 是否能渲染。可视化 AI 不再直接编写易损坏的 draw.io XML，而是返回受约束的节点、连线和泳道计划，由本地编译器确定性生成 XML，并检查重复 ID、悬空连线、父级引用、坐标结构和 XML 安全性。修改已有可视化画布时优先使用局部补丁，保留未涉及图形的位置和样式。除“解释当前图”外，结果只有在用户点击“应用到画布”后才会写入，应用前会保存版本快照；校验失败时可以直接修复当前候选，无需重新描述需求。

## 安全约定

- 不要把密钥填入任何以 `VITE_` 开头的变量；这类变量会进入前端代码。
- 网页开发环境的 AI 设置默认保存在服务端 `.data/ai-providers.json`；桌面版保存在 Electron 用户数据目录的 `ai-providers.json`。这些位置不会进入图表备份。
- `.env.local` 仍可作为服务器部署时的环境变量备用配置。
- AI 只读取当前页面的图表、当前项目所选对话和用户主动添加的附件，不主动读取其他项目、旧版本或本机其他文件。界面中的上下文提示会明确显示本次是否识别到当前图。
- 本地代理用于避免把 API Key 暴露给前端，但图表内容仍会传给用户选择的模型服务。
- 桌面安装版和本项目的桌面开发预览共用 `fengsha-diagram-workbench` 用户数据目录；重新编译、重启或覆盖升级不会要求重新填写 API Key。旧开发版如果曾把 AI 配置写入 Electron 默认目录，新版会在正式目录为空时自动迁移一次，且不会覆盖已有配置。
- 桌面应用会保留稳定的本地访问来源。首次升级时会优先识别最近使用的旧来源，以继续读取原有项目、已启用模型和工作区偏好；随后固定使用该来源，避免随机端口变化造成“配置消失”的假象。

更多操作步骤和故障排查见 [完整用户指南](user-guide.md)。
