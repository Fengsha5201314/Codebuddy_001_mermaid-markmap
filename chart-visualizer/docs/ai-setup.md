# AI 模型接入说明

当前支持 **CPA AI**、**DeepSeek** 和一个 **OpenAI 兼容的自定义 API**。密钥由本地服务端保存，不会写入浏览器、本地图表数据或导出文件。

> 使用 AI 时，当前图表内容和本次指令会发送给所选模型服务。请先确认该服务可以处理你的数据，不要发送密码、密钥或未经授权的敏感资料。

## 首次配置

1. 打开右上角“设置”。
2. 进入“AI 模型”。
3. 在 CPA、DeepSeek 或自定义 API 中填写接口地址与 API Key，然后点击“保存连接”。
4. 点击“获取模型”，从下拉框选择模型，再点击“启用模型”。
5. 回到 AI 助手，从“本次使用”下拉框选择已启用模型。

可以同时启用多个模型。AI 对话区的“本次使用”下拉框只会显示已启用的模型，并允许随时切换。

## 专业任务模板与统一识别

AI 助手不再要求用户先选择“新建、修改、修复或解释”。打开助手后，可以直接描述需求，也可以点击“优化结构”“补全流程”“排查问题”“转换图种”“解释与评审”“从描述创建”等专业任务模板，把对应提示词加入输入框后继续补充细节。

提交时，软件会先识别当前页面是否存在 Mermaid 源码或可视化画布：有内容时会把当前图与需求一并发送，由 AI 判断应当修改、修复、转换还是仅做解释；没有内容时才会从描述创建新图。提交后内容会边生成边显示，需要中止时可以点击“停止”。

完整结果返回后，软件会先检查 Mermaid 是否能渲染，或检查 draw.io XML 结构。除“解释当前图”外，结果只有在用户点击“确认应用”后才会写入；应用前会保存版本快照。校验失败的结果会显示错误，不允许直接覆盖当前图表。

## 安全约定

- 不要把密钥填入任何以 `VITE_` 开头的变量；这类变量会进入前端代码。
- 网页开发环境的 AI 设置默认保存在服务端 `.data/ai-providers.json`；桌面版保存在 Electron 用户数据目录的 `ai-providers.json`。这些位置不会进入图表备份。
- `.env.local` 仍可作为服务器部署时的环境变量备用配置。
- AI 只读取当前页面的图表和本次指令，不主动读取其他本地图表或旧版本。界面中的上下文提示会明确显示本次是否识别到当前图。
- 本地代理用于避免把 API Key 暴露给前端，但图表内容仍会传给用户选择的模型服务。

更多操作步骤和故障排查见 [完整用户指南](user-guide.md)。
